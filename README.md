
# Nexa Salon

EGN 475 - Software Prototyping

Student: Bishnu Bahadur GC

Instructor: Prof. Gabriel Cespedes

## Project Description
Nexa Salon is a salon appointment booking prototype designed to make booking haircuts, coloring, and styling services easier.

## Technologies
- Python 3.12
- Flask 3.1.3
- Visual Studio Code
- Git and GitHub

## Current Features
- Home page (/)
- About page (/about)

## How to Run
1. Create and activate a Python virtual environment.
2. Install dependencies using:
   pip install -r requirements.txt
3. Start the application using:
   flask --app app run --debug
4. Open http://127.0.0.1:5000
