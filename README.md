## How to Run
1. Create and activate a Python virtual environment.
2. Install dependencies using:
   pip install -r requirements.txt
3. Start the application using:
   flask --app app run --debug
4. Open http://127.0.0.1:5000

## Week 1 Assignment 1.2 – Project Planning

### Project Choice
Option B: Salon Appointment Booking (Nexa Salon, based on Bella Vista Salon).

I chose the salon booking project because appointment scheduling is a common challenge for small businesses. A simple online booking system can help clients save time and help salon staff organize appointments more efficiently.

### Problem Statement
Nexa Salon currently handles appointment requests through phone calls and staff communication. This can cause delays and confusion for clients who want to book services and for staff who manage the schedule. Our prototype will allow clients to view services, choose an available stylist and appointment time, and request bookings, while staff can manage appointment statuses, so that booking becomes faster, clearer, and more organized.

### Target Users

**Persona 1: Maya Sharma – Salon Client**
- Role: Returning salon client
- Main goals: Find available appointments quickly, compare services and prices, and book a preferred stylist.
- Frustrations: Waiting for staff responses and uncertainty about appointment availability.
- Technology comfort: High; regularly uses websites and smartphone apps.
- Quote: "I want to book my haircut when I have time, without waiting for someone to answer the phone."

**Persona 2: Daniel Lopez – Salon Receptionist**
- Role: Receptionist responsible for scheduling appointments
- Main goals: Keep bookings organized, avoid overlapping appointments, and update appointment statuses.
- Frustrations: Repeated phone calls, scheduling conflicts, and last-minute changes.
- Technology comfort: Moderate; comfortable with basic scheduling software.
- Quote: "I need one clear schedule so I can help clients without double-booking anyone."

### Must-Have Features
1. View salon services, prices, and estimated durations.
2. Select a service and available stylist.
3. Choose an available appointment date and time.
4. Enter client name and contact details.
5. Review and submit an appointment request.
6. View appointments and request cancellation or rescheduling.
7. Staff calendar to confirm, complete, or cancel appointments.
8. Staff service management to add or update service details.

### Not in This Prototype
1. Online payments or deposits.
2. SMS or email reminder automation.
3. Native Android or iOS mobile applications.
4. Loyalty points and rewards.
5. Advanced payroll and employee management.
